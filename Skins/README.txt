把 PNG 贴图放进这里的子文件夹即可成为一套皮肤：主菜单点「皮肤」切换（下一局生效）。
例如：Skins/我的皮肤/note.png → 选择「我的皮肤」后音符变为该贴图。

支持的文件名（缺哪个用内置程序化外观）：
  note.png      四轨音符（建议 512x256 圆角横条）
  holdbody.png  hold 光带（建议 128x256，纵向渐变，底端为音头端）
  pad.png       按键板（建议 384x192 圆角）
  disc.png      太鼓圆盘/鼓垫（建议 256x256 圆形）
  rollstrip.png 太鼓连击条（建议 64x128 横向柔边条）

—— 兼容 osu! 皮肤（推荐，海量现成贴图）——
把任意 osu 皮肤文件夹里的图片直接拷进来也认，自动回退识别：
  mania-note1T.png / mania-note1.png 等 → 音符
  taikohitcircle.png / taikohitcircle-k.png → 太鼓圆盘
osu 皮肤下载站：osuskins.net、skinship（Discord 工坊）等，搜索 mania / taiko 分类。
注意：osu 皮肤多为粉丝制作、可能含游戏 rip 素材，请仅个人使用，勿随仓库分发。

—— 可自由使用（CC0）的素材来源 ——
  kenney.nl          CC0，UI Pack / Game Icons / 圆形按钮等
  opengameart.org    筛选许可 CC0，搜 rhythm / notes / arrows / ui
  itch.io/game-assets 筛选 Free + CC0
